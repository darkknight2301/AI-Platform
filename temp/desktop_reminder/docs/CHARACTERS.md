# Adding a character

A character is a folder with a `manifest.json`. Put it in **`assets/characters/<name>/`**
(or, for built-ins, `app/characters/builtin/<name>/`). It appears in the Settings and reminder dialogs
the next time the app starts. A user folder with the same `id` overrides a built-in one.

You never edit `scheduler.py`, `reminder_manager.py` or `reminder_store.py`.

## Option A – art only (no code)

```
assets/characters/cat/
    manifest.json
    walk_0.png walk_1.png walk_2.png walk_3.png
    idle.gif
    reminder.png
    happy_sheet.png
    angry_0.png angry_1.png
    sounds/               (optional per-character overrides: enter.wav, happy.wav, ...)
```

```json
{
  "id": "cat",
  "name": "Whiskers",
  "size": [128, 128],
  "faces": "left",
  "animations": {
    "walk":     {"type": "png_sequence", "pattern": "walk_*.png", "fps": 8},
    "idle":     {"type": "gif", "file": "idle.gif"},
    "reminder": {"type": "png_sequence", "files": ["reminder.png"]},
    "happy":    {"type": "spritesheet", "file": "happy_sheet.png",
                 "frame_width": 128, "frame_height": 128, "count": 6, "fps": 10},
    "angry":    {"type": "png_sequence", "pattern": "angry_*.png", "fps": 14}
  }
}
```

| Key | Meaning |
|---|---|
| `id` | unique id stored in reminders (defaults to the folder name) |
| `name` | label shown in the UI |
| `size` | `[width, height]` the art is scaled into (aspect kept, bottom-aligned) |
| `faces` | direction the art looks: `left` (default) or `right`. The overlay mirrors it automatically when walking the other way |
| `animations` | `walk`, `idle`, `reminder`, `happy`, `angry` (all optional – see fallbacks) |

Animation types: `png_sequence` (`pattern` glob or `files` list), `gif` / `webp` (`file`),
`spritesheet` (`file`, `frame_width`, `frame_height`, optional `count`). Common options: `fps`, `loop`.

Art tips: transparent PNGs, feet at the bottom edge, same canvas size for every frame.
Missing or unreadable animations are logged and replaced by the fallback chain
(`reminder/happy/angry → idle → walk → placeholder box`), so a half-finished character never crashes the app.

Sample: `assets/characters/robot/` (generated by `tools/generate_assets.py`).

## Option B – custom behaviour/drawing (a little code)

Add `"entry": "character.py"` to the manifest and expose a factory:

```python
# assets/characters/dog/character.py
from app.characters.sprite_character import SpriteCharacter
from app.characters.animation import ProceduralAnimation

class Dog(SpriteCharacter):
    def load_animations(self):            # return {name: Animation}
        return {"walk": ProceduralAnimation(draw_walk), "idle": ...}

def create_character(info, context):      # required name
    return Dog(info, context)
```

`built-in/default_character/character.py` is a complete example (all-procedural "Pebble").
Override more of `SpriteCharacter` (or implement `BaseCharacter` from scratch) if you need different
choreography, e.g. a character that hops instead of walking. The only contract the rest of the app uses:

```python
show_reminder(reminder)      # enter + present, non-blocking
react("completed"|"snoozed") # reaction animation, then leave
hide(immediate=False)
# and: self._set_state(...), self._emit_action(...), self._notify_finished()
```

A plugin that raises during load is logged and the default character is used instead.

## Checklist

1. Folder + valid `manifest.json` (`python -m json.tool manifest.json`).
2. Restart the app, choose the character in Settings → *Test character animation*.
3. Check `logs/desktop_reminder.log` for "animation unavailable" warnings.
4. Only use artwork you created or are licensed to use.
